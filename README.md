# SSI Security Labs

Colección de prácticas académicas realizadas en la asignatura
**Seguridad en Sistemas Informáticos** del Grado en Ingeniería Informática
de la Universidade de Vigo.

Los laboratorios fueron realizados exclusivamente en entornos controlados
y redes virtuales preparadas con fines docentes.

## Contenidos

### Seguridad web
- Pruebas de Cross-Site Scripting (XSS)
- SQL Injection
- DVWA
- Detección y mitigación mediante ModSecurity

### Redes y análisis de tráfico
- ARP Spoofing y Man-in-the-Middle con Bettercap
- Captura y análisis con Wireshark y tshark
- Comparación TELNET / SSH
- Comparación HTTP / HTTPS

### Seguridad de infraestructura
- Implementación de una DMZ con doble firewall
- Configuración de Shorewall
- Validación de reglas y exposición de servicios con Nmap

### IDS / detección
- Suricata
- Reglas de detección para tráfico ICMP
- Detección de escaneos TCP
- Detección de User-Agent sospechoso
- Análisis de eventos mediante eve.log

## Objetivo

Estas prácticas forman parte de mi formación introductoria en
ciberseguridad y tienen como objetivo comprender de forma práctica
conceptos de seguridad web, redes, detección y defensa de infraestructura.

> Todo el contenido corresponde a laboratorios académicos realizados
> en entornos aislados y autorizados.
